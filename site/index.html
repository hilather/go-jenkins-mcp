Why it exists

Agents that can read CI must not become a backdoor into Jenkins.

Built as an enterprise product from a community seed — not a thin wrapper. Architecture packages for auth, policy, archive, redaction, and tools are first-class.

Secrets stay off the model path

Profiles hold non-secret connection data. API tokens land in Secret Service after interactive login — never in Cursor mcp.json, shell history, or profile JSON.

Diagnosis tools, not just raw logs

Structured diagnose, compare, regression windows, survey, search, and mirror flows with hard response budgets so agents get signal instead of multi-megabyte pastes.

Policy you can sign and audit

Deny-only RBAC overlays, Ed25519 signed policy bundles, mutation preview/confirm with cooldowns, and offline doctor / security self-checks for pilot evidence.

Capability surface

What agents can actually call.

Core job/log tools always register in the RO pilot path. Higher-order diagnostics and optional adapters layer on when you enable them.
