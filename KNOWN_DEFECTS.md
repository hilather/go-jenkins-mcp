# Known seed defects (expected to change)

Documented for **FND-003** so contract tests do not enshrine unsafe behavior as
desired end-state. Seed baseline:
`upstream-simonfxr-baseline` / commit `83f66a9c57c0bc26044f654e589b6361787f0c89`.

| ID | Area | Defect | Target fix | Status |
|----|------|--------|------------|--------|
| KD-001 | Logs | Progressive log path used `io.ReadAll` on progressiveText; full remainder loaded then truncated | LOG-001 hard LimitReader caps | **Fixed** (2026-07-31): app buffers / returned payload ≤ request; early body close. Residual: Jenkins may still generate response bytes on the wire until connection close; fixture wire can exceed request by a small write-buffer multiple (~1–8×) but not by full logical size |
| KD-002 | Logs | Log tail probed `start=0` and could download the full log when sizing | LOG-001/LOG-002 | **Reduced** (LOG-001): when `X-Text-Size` is present, size probe does not materialize the body; tail fetches `start=max(0,size-L)` with a LimitReader. Residual: without `X-Text-Size`, a true tail is unavailable — probe is bounded to `maxLength` and returns a prefix, not a seeked tail |
| KD-003 | Credentials | Auth via `-auth user:token` or `JENKINS_MCP_AUTH` (secret in CLI/env) | AUTH-002/003 OS Secret Service + login commands | **Mitigated (AUTH-001/002):** profile + keyring preferred; legacy `-auth`/env bootstrap-only with warning |
| KD-004 | Auth log | Username logged at startup; token must never appear (partial) | redact / structured logging (OBS/SEC) | **Reduced** (Wave 22–25, **33–34**): `log.SetOutput(redact.NewWriter)` + labeled detectors + **bare high-entropy** (`CategoryBareToken`: single-case hex ≥40, mixed-case hex ≥32, base64url-like ≥24–32 + diversity; W3C 32-hex trace_id preserved) + **line-buffered Writer** (reassemble incomplete lines across Writes; Flush/Close redacts remainder; concurrent-safe) + **force-flush carry** (256 B tail kept when pending exceeds 256 KiB without `\n` so typical secrets straddling that boundary rejoin).
